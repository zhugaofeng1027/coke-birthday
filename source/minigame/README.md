# 生日小厨房 · 微信小游戏原型

这是独立于 GitHub Pages 的测试工程，只包含第 1 关和可直接进入的吹蜡烛测试。第 1 关与网页共用配方、订单时间、扣分、通关规则、厨房绘制和原创 BGM。不包含其他五关、开场和 DIMOO 隐藏关，不共享网页存档。

## 本地预览

从仓库根目录运行 `npm run dev:wechat`，打开 `http://127.0.0.1:5181/`。预览在浏览器里模拟微信触控、横屏尺寸和音频接口，不提供真实录音。可使用 `npm run test:wechat` 跑标准和窄横屏的浏览器测试；`npm test` 包括共享关卡以及 PCM 吹气检测测试。

## 微信真机

1. 运行 `npm run build:wechat`，在微信开发者工具中选择「导入项目」，目录使用仓库根目录下的 `dist-wechat/`，项目类型选小游戏。
2. 工程默认使用 `touristappid`（用于本地调试）。要生成微信真机预览码，在开发者工具中切换为自己的小游戏 AppID，并用有开发权限的微信账号登录。重新构建会重建输出目录，所以不要只在输出目录保存需要长期保留的配置。
3. 如要测试录音，在微信公众平台为该小游戏声明实际使用的麦克风用途，并配置平台隐私授权弹窗。小游戏仅在主动进入吹蜡烛测试并点「用气息吹」时请求权限。音频分片仅在设备本地判断，退出、吹灭或切到后台会停止录音，不上传录音。拒绝或不可用时可点按吹灭。
4. 在开发者工具中点「预览」，用有权限的微信账号扫码；至少在一台 iPhone 和一台安卓机检查横屏胶囊位置、双指操作、切后台恢复、实际 BGM 和真吹气。开发者工具与浏览器结果不能替代真机验证。
