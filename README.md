# 生日小厨房

一个手机优先的实时厨房生日游戏。基于 Phaser Arcade Physics 实现主厨移动与台面碰撞，使用原创 Canvas 美术，不使用原作游戏素材。

六间主题厨房依次解锁六份生日礼物。每关需要亲自取材、切配、煮制或烘烤、等待熟成、装盘，按该厨房的线索完成出餐。礼物名称只在生日便笺揭晓后出现。

## 六间厨房

| 厨房 | 料理 | 特别机关 | 礼物 |
| --- | --- | --- | --- |
| 果园甜品站 | 双果酱烤吐司 | 根据形状与颜色选材，同锅熬出爱心果酱，抹上烤吐司 | 果汁软糖 |
| 口袋便当铺 | 山尖饭团便当 | 端熟米饭压模具，按盒盖图案逐格装便当 | Chiikawa 挂件 |
| 深夜卤味档 | 深夜慢卤牛肉 | 逐味取香料装袋，亲手下锅成卤汤，再下牛肉 | 卤货零食大礼盒 |
| 时光食堂 | 照片里的双人餐 | 对照餐照，亲手将三份料理放到左中右餐格 | 拍立得相纸 |
| 月光香草厨房 | 薄荷热茶与烤面包 | 端热茶靠近玻璃显字，按线索把茶和面包送到灯旁、花下 | 香薰 |
| 花园餐厅 | 生日主厨拼盘 | 按前奏、主调、尾声摆盘，点亮花园 | 古驰香水礼盒 |

右下角的特别工作台提供关卡线索与机关操作，必须走近才能操作。只有最终拼盘仍使用餐序表单；前五关的机关直接融入做菜动作。所有机关均可反复尝试，没有倒计时惩罚。厨房仅使用可食用的薄荷与普通食材，香薰和香水仅作为揭晓的礼物。

各厨房的实际机关：

- 果园：切好的草莓与葡萄同锅熬煮，只有正确组合才冒爱心；猕猴桃或重复水果不会通过。配错后可把新的切好水果加入锅中，替换不合适的那份，不影响已烤好的吐司。果酱与烤吐司放到同一餐盘时自动抹酱，完成配方。
- 便当：煮好的米饭端到右下角模具台，每次操作依次压成圆形、三角形、爱心，选出盒盖上的山尖。空盘先放到下方餐盘提手台，再把饭团、烤鸡、切好的西兰花逐一放进右边的左、中、右三个餐格。空手操作某一格可以取回该份料理；拿着另一份料理操作则直接交换，其他食物保留。完成后到提手台端起整盘，送至左侧取餐口。
- 卤味：下方四罐香料可逐味取出，送到右下角卤料袋。星星、木筒、叶子分别对应八角、桂皮、香叶，辣椒和重复香料不会通过。配错可空手取回最后一味，再放回原罐。配齐后再操作一次拿起袋子，亲手放进煮锅才会成为卤汤；之后切肉、卤牛肉和胡萝卜，装盘送至左侧取餐口。
- 时光：右下角餐照是摆盘参照。煮番茄热汤、烤吐司、切蘑菇，再像便当一样逐格放到红、金、浅棕对应的左、中、右餐格。放错可单独取回调换。提手台端起整盘，送至左侧取餐口，出餐后生成相片便笺。
- 月光：必须端着已煮好的薄荷茶，在右下角玻璃前连续停留两秒，锅中或远处的茶不会显字。根据“热茶留在灯旁，面包放在花下”，将茶留在左侧灯旁，把装盘的烤面包送到右下花下餐位。也可先同盘装好，餐位会取走对应那份；放错位置保留手中料理。两处送齐后自动出餐。

时光食堂当前使用原创占位餐照，尚未接入你们的真实照片；最终餐序是游戏叙事，不对应任何具体香水的实际香调。

## 操作

- 手机横屏：厨房居中，左侧摇杆移动，右侧大按钮负责取放与操作，持续按住切配按钮切菜或切肉。菜谱和手持物品分别显示在两侧，整屏无需上下滚动；顶部可查看提示、礼物簿和设置。
- 手机竖屏时提示旋转，并暂停移动和烹饪计时；转回横屏继续同一份料理，不会重开关卡。支持全屏的浏览器可使用顶部全屏按钮。
- 电脑：方向键或 WASD 移动，E 取放与操作，按住空格切配，也支持鼠标操作摇杆和按钮。
- 一次只能拿一份食材或一个餐盘，靠近对应工作台才能操作。
- 盘子架在左侧，切配台和煮锅在中间，烤箱在右侧，特别工作台在右下角。第二至四关取餐口在左侧，其余关卡在下方；第二、四关下方右侧是三个独立餐格，第三关这里是四罐香料。
- 食物切好后才能烹饪；吐司不需要切配。锅和烤箱自动计时，可以并行备菜。
- 先把空盘放在装盘台，再逐个加入处理好的食材；也可以直接用端着的盘子从锅和烤箱盛取熟食。
- 食物熟了不会烧焦。拿错食材可以送到左下方回收桶，或重新制作当前菜品。
- 打开弹窗、切到其他应用时，移动和烹饪计时暂停。

## 运行

```bash
npm install
npm run dev
```

浏览器访问终端显示的地址。右上角二维码可在同一 Wi-Fi 下用手机体验，电脑需要保持运行。

电脑调试可点击顶部手机图标，或打开 `http://localhost:5173/?preview=phone`。预览器提供固定手机/平板横屏尺寸，会自动缩放以适应电脑窗口；可直接使用方向键/WASD、E、空格游玩。切换预览尺寸不重开料理。普通电脑窗口即使很窄也不再强制显示旋转提示；`?layout=desktop` 可显式使用电脑布局。

开发服务右上角的虫形图标是“关卡调试”：选择“开发调试”和任意关卡，点击“进入厨房”即可自由跳关，也可使用左侧关卡菜单。调试通关、礼物揭晓、重置和结尾均不写入正式存档；调试完成后仍可继续测试下一关。通过同一入口选择“正式闯关”，恢复原来的正式进度和关卡锁定。切换模式或跳关会重开料理。`?debug=1&chapter=4` 可直接调试第四关，也能与 `?preview=phone` 一起使用；刷新保留调试关卡，但重新开始料理。正式构建不提供调试入口，且忽略调试参数；分享二维码会移除调试参数。

```bash
npm test
npm run build
npm run test:e2e
```

端到端测试需要先启动开发服务器并执行 `npx playwright install chromium` 安装测试浏览器。测试包括真实按键移动、碰撞、持续切配、实际等待烹饪、六关机关、触屏摇杆与礼物流程。六关完整流程在桌面和手机运行，其他尺寸也覆盖首关和横屏布局。

## 修改生日内容

右上角设置可编辑称呼、署名、六份礼物的谜面、揭晓后的留言和结尾。保存仅作用于当前浏览器。

要让手机或正式站点使用修改后的内容，在设置中点击“导出当前表单”，将下载的 `config.json` 替换 `public/config.json`，重新构建部署。也可以直接修改这个源文件。配置和游戏进度分别保存在本机 localStorage 中，重置进度不会清除文案。

默认礼物顺序为：果汁软糖、Chiikawa 挂件、卤货零食大礼盒、拍立得相纸、香薰、古驰香水礼盒。实际礼物请按 01–06 编号包装。

## 部署与二维码

`npm run build` 生成 `dist/`，可发布到支持静态文件的 HTTPS 网站。必须同时部署 `dist/config.json`。二维码使用当前域名；部署后再制作正式二维码，不能把 localhost 或局域网二维码用于异地访问。

本项目不包含用户注册、联网对战、云端同步和付费服务。音乐通过 Web Audio 合成，默认静音，点击顶部音量按钮开始。新厨房玩法使用独立的 v2 关卡存档，不会删除旧版解谜存档或自定义生日文案。

礼物的答案保存在客户端，适用于私人生日惊喜，不用于需要防作弊或保密的场景。
